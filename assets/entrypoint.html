Cookie & Click Logger - Measurement Entrypoint

Welcome! Use this dialog as startingpoint for your measurement. Please note the following warnings before starting:

Warning

  • The setting/editing/deletion of cookies can only be detected across the entire browser and cannot be assigned to a single tab. It is therefore important that only one tab is open in order to rule out external influences on the measurement.
  • When the measurement starts, all tabs (except this one, which can remain open as it does not use cookies) are automatically closed and all browsing data (such as cookies, cache, local storage) is deleted.
  • It is recommended that you create a separate browser profile for the measurement to avoid the loss of personal data (cookies, cache).

For measurement you can use one of the predifined websites of the following list, or enter a custom url down below. When you are ready just hit the "Start" Button.

Hint: To simplify the measurement process for multiple pages, each click on the start button directly selects the next page in the list.

Please keep in mind to stop each measurement when you are done because otherwise no further measurements can be started!
